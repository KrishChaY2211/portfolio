# Krishchay's Portfolio

My personal portfolio page — a single, hand-written HTML file with no frameworks,
no build step, and no dependencies. I built it early in my coding journey to have
a place online that was mine, and I've kept it as a marker of where I started.

## What's here
- `index.html` — the entire page: a short profile, my hobbies, and "my story"
- `knight.jpg` — the header image
- `krishna.jpeg` — used as the page icon

## View it
Open `index.html` in any browser — there's nothing to install.

_(Optional: turn on GitHub Pages in Settings → Pages to host it live.)_

## A note
The markup is simple and a little nostalgic — it's a snapshot of my first steps in
web development. A cleaner, responsive rebuild is on my list.
